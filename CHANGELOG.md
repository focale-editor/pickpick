# 📰 Pickpick changelog

## 0.1.0

- Extract Focale's system screen picker into an independent Flutter plugin.
- Add a native Windows picker using Win32 input and single-pixel sampling.
- Support Linux desktop portals, macOS `NSColorSampler`, and browser `EyeDropper`.
- Validate opaque sRGB results and preserve cancellation and error handling.
- Include macOS CocoaPods and Swift Package Manager integration.
